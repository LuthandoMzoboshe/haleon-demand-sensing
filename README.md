# 🏥 Haleon Demand Sensing Pipeline

## Problem Statement
Consumer healthcare products experience unpredictable demand spikes driven by weather changes, flu outbreaks, and seasonal patterns.

## Solution
Automated pipeline calculating real-time Demand Risk Score per product per region.

## Tech Stack
- Orchestration: Apache Airflow
- Processing: PySpark, dbt
- Storage: Azure Blob (Bronze/Silver/Gold)
- Quality: Great Expectations
- Viz: Power BI
